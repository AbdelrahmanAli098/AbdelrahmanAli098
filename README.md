## 🚀 Featured Projects

### 🤖 Production-Ready RAG Application
*Python · FastAPI · Qdrant · Ollama · Inngest · Streamlit · Docker*

A full RAG system letting users upload PDFs and query them in natural language — featuring a scalable ingestion pipeline (chunking, embeddings, vector indexing), event-driven processing with Inngest, local LLM inference via Ollama, and a Streamlit front end. Fully containerized for reproducible deployment.

---

### 🎓 University Recommendation System — Graduation Project *(Awarded A+)*
*FastAPI · MySQL · Flutter · Dart · Scikit-learn*

A content-based filtering + gradient boosting recommender that matches students to suitable public, private, and national universities, paired with a Flutter mobile front end and a FastAPI/MySQL backend.

---

### 🪪 Face Verification System (Siamese Networks)
*TensorFlow · Keras · OpenCV · Kivy*

A real-time face verification app powered by a Siamese neural network trained on anchor–positive–negative triplets, with a live webcam pipeline and a lightweight Kivy GUI for capture and verification feedback.

---

### 🚗 Real-Time Vehicle Counting System
*YOLOv8 · SORT · OpenCV*

A real-time computer vision pipeline combining YOLOv8 detection with SORT tracking for persistent IDs, directional line-crossing logic, region masking, and live visualization of vehicle counts.

---

### 📄 AI-Powered PDF Summarization Tool
*FastAPI · EasyOCR · Hugging Face (BART) · Docker*

An OCR-to-summary pipeline: extracts text from scanned PDFs with EasyOCR, cleans and chunks it, then summarizes with `facebook/bart-large-cnn` — exposed via an asynchronous FastAPI service and containerized with Docker.
